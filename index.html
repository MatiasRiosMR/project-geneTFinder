Sobre el proyecto

GeneTFinder es una herramienta para descubrir y priorizar factores de transcripción a partir de datos ómicos. Ofrece un pipeline reproducible, visualizaciones claras, y un dashboard con métricas operativas y científicas en tiempo real.

  • Integración de múltiples fuentes (motifs, ChIP, expresión).
  • Scoring transparente y trazable.
  • Exportación de resultados y endpoints para automatización.

Tiempo real

Actualización continua vía WebSocket/SSE o simulación local sin backend.

UX moderna

Animaciones sutiles, scroll-snap y diseño responsivo.

Escalable

Arquitectura preparada para crecer y exponer APIs.
