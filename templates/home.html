Acerca del proyecto

Arquitectura actualizada, flujo y mejoras recientes

GeneTFinder es una herramienta para predecir si una proteína actúa como factor de transcripción a partir de su secuencia. Integra un servicio de inferencia con una API y una interfaz moderna, pensada para investigación y docencia.

Arquitectura actualizada

Diseño modular con separación de responsabilidades

Servicio de Inferencia

Modelo de deep learning empaquetado como servicio aislado. Soporte para CPU/GPU y batching para alto rendimiento.

Flujo de procesamiento

1) Ingreso de secuencia → validación y normalización.
2) Envío a la API → enrutamiento al servicio de inferencia.
3) Inferencia del modelo → tokenización/embeddings y predicción.
4) Post-procesado → probabilidades, umbrales e interpretabilidad.
5) Respuesta JSON/HTML → registro y métricas.

Cambios recientes

Modularización

Separación clara entre API, inferencia, autenticación y datos para facilitar mantenimiento y despliegue.

Rendimiento

Batching y caché de inferencia para latencias menores y mejor throughput bajo carga.

Configuración

Variables de entorno y perfiles por entorno para despliegues reproducibles.

Seguridad

Mejoras en sesiones, políticas de acceso y protección de endpoints sensibles.
