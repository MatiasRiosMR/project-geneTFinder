GeneTFinder — Proyecto

GeneTFinder es un prototipo para clasificar factores de transcripción (TF) a partir de secuencias proteicas. Usa modelos 1D-CNN mejorados y técnicas de calibración para ofrecer probabilidades más fiables.

Características

  • Arquitectura: Conv1D, BatchNorm, Dropout y capas densas.
  • Entrenamiento: balance de clases, early stopping y temperature scaling.
  • Soporte para checkpoints PyTorch (.pt) y modelos Keras (.h5).
  • Interfaz: predicción en web, historial, exportación CSV y panel admin.

Uso rápido (Modelos y recarga)

Para que la aplicación use un modelo entrenado, coloca el checkpoint PyTorch (.pt) en la raíz del proyecto con nombre GeneTFinder_model.pt o define la variable de entorno MODEL_PATH apuntando al archivo.

  • Ruta por defecto: c:\Users\matia\OneDrive\Escritorio\GeneTFinder\GeneTFinder_model.pt
  • Si usas un .h5, ubícalo como GeneTFinder_model.h5 en la misma carpeta o artifacts/.
  • Desde la interfaz Admin puedes pulsar Recargar modelo para forzar la carga sin reiniciar el servidor.

Si la inferencia falla el servidor devolverá una predicción provisional (fallback) con una explicación; esto permite continuidad mientras se depura el modelo.
