Acerca de GeneTFinder

GeneTFinder es un proyecto de clasificación de factores de transcripción usando redes neuronales convolucionales (CNN) entrenadas localmente.

Características principales

  • Predicción de TFs usando CNN con atención
  • Soporte para modelos PyTorch (.pt) y Keras (.h5)
  • Interfaz web moderna y accesible
  • API REST para integración

Instrucciones de uso

  1. Coloca tu modelo entrenado en la carpeta raíz: GeneTFinder_model.pt o GeneTFinder_model.h5
  2. Usa el panel Admin → Recargar modelo para activar sin reiniciar
  3. Pega una secuencia o sube un archivo FASTA
  4. ¡Predice y explora los resultados!
